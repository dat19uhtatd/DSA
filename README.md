## Data Structures and Algorithms (DSA) Repository

---

###  Overview

This repository is dedicated to my journey in learning and practicing **Data Structures and Algorithms (DSA)**. It serves as a comprehensive collection of problems, solutions, and explanations implemented across various programming languages.

###  Goal

The primary goal of this repository is to:

1.  **Strengthen** my foundational knowledge of essential Data Structures.
2.  **Improve** my problem-solving skills and algorithmic thinking.
3.  **Maintain** a documented record of my progress and learned concepts.
4.  **Prepare** for technical interviews.

###  Repository Structure

The repository is organized by Data Structure and Algorithm type for easy navigation.

* `./data_structures/`: Contains implementations of core data structures.
    * `arrays/`
    * `linked_lists/`
    * `stacks_queues/`
    * `trees/` (Binary Trees, BST, AVL, Red-Black, etc.)
    * `graphs/`
    * `hash_tables/` (Maps/Dictionaries)
    * `heaps/` (Min/Max Heaps, Priority Queues)
* `./algorithms/`: Contains implementations of general algorithms and techniques.
    * `sorting/` (Merge Sort, Quick Sort, Heap Sort, etc.)
    * `searching/` (Binary Search, DFS, BFS)
    * `dynamic_programming/`
    * `greedy_algorithms/`
    * `backtracking/`
* `./problems/`: Solutions to specific problems from platforms like LeetCode, HackerRank, etc., categorized by topic.
    * `leetcode/`
    * `hackerrank/`

###  Data Structures Covered

| Data Structure | Description |
| :--- | :--- |
| **Array** | Collection of items stored at contiguous memory locations. |
| **Linked List** | Linear structure where elements are not stored at contiguous locations. |
| **Stack** | LIFO (Last-In, First-Out) structure. |
| **Queue** | FIFO (First-In, First-Out) structure. |
| **Tree** | Non-linear, hierarchical structure.

| **Graph** | Collection of nodes (vertices) and connections (edges).  |
| **Hash Table** | Structure that implements an associative array abstract data type, using a hash function. |
| **Heap** | Specialized tree-based data structure that satisfies the heap property. |

###  Algorithms Covered

| Algorithm Type | Examples | Key Concepts |
| :--- | :--- | :--- |
| **Sorting** | Bubble Sort, Merge Sort, Quick Sort | Time Complexity, In-place vs. Out-of-place |
| **Searching** | Linear Search, Binary Search, DFS, BFS | Divide and Conquer, Graph Traversal |
| **Dynamic Programming** | Knapsack Problem, Longest Common Subsequence | Overlapping Subproblems, Optimal Substructure |
